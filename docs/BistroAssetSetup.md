# Bistro Asset Setup

The NVIDIA ORCA Bistro bundle is not tracked in Git for this repository.

Download it from:

https://developer.nvidia.com/orca/amazon-lumberyard-bistro

Place the extracted folder at:

`assets/models/fbx/bistro_v5_2/`

Required files used by the scene:

- `BistroInterior_Wine.fbx`
- `BistroInterior.fbx`
- `BistroExterior.fbx`
- `Textures/`

The scene expects the folder structure to remain intact so Assimp-relative texture paths continue to resolve locally.
